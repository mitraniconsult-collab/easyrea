# EasyRea → Shopify синхронизация — Ръководство

## Какво прави
Всяка нощ автоматично сверява наличността на 4-те бранда от easyrea с твоя Shopify:
- **В наличност** → продуктът е активен, с наличност
- **На път (In arrival)** → наличност 0 + дата на пристигане в metafield (за клиента)
- **Изтрит от easyrea** → продуктът отива в DRAFT (скрит)

Свързването е по код: `codeArticle` от easyrea = `SKU` в Shopify (вече потвърдено, че съвпадат).

---

## Стъпка 1 — инсталирай
```bash
pip install requests
```

## Стъпка 2 — Shopify Admin API токен
1. Shopify админ → **Settings → Apps and sales channels → Develop apps**
2. **Create an app** → дай име (напр. "EasyRea Sync")
3. **Configure Admin API scopes** — включи:
   - `read_products`, `write_products`
   - `read_inventory`, `write_inventory`
4. **Install app** → копирай **Admin API access token** (`shpat_...`)
5. Вземи Location ID: в скрипта има как, или от Settings → Locations

## Стъпка 3 — въведи данните в приложението
Най-лесно: пусни `app.py`, попълни полетата горе вляво и натисни
„Запази настройките". Приложението ги подава на скриптовете като
environment променливи при всяко стартиране.

Ръчно (Linux/Mac), ако пускаш скрипт извън приложението:
```bash
export EASYREA_LOGIN="..."
export EASYREA_PASSWORD="..."
export SHOPIFY_STORE="твоя-магазин.myshopify.com"
export SHOPIFY_CLIENT_ID="..."
export SHOPIFY_CLIENT_SECRET="..."
export SHOPIFY_LOCATION_ID="gid://shopify/Location/123456789"
export ANTHROPIC_API_KEY="..."
```
НЕ ги пиши в кода. Скриптовете спират веднага, ако липсват.

## Стъпка 4 — пробвай в БЕЗОПАСЕН режим (нищо не променя)
```bash
python3 sync.py --dry-run
```
(или включи чекбокса „ТЕСТ (DRY RUN)" в приложението)
Получаваш CSV отчет `sync_report_*.csv` със списък: кой продукт какво действие
ще получи (IN_STOCK / ARRIVING / DRAFT) и защо. **Нищо не се пипа в Shopify.**

Прегледай отчета. Ако изглежда правилно →

## Стъпка 5 — включи реалните промени
Изключи чекбокса „ТЕСТ (DRY RUN)" в приложението (ще те попита за
потвърждение), или от команден ред:
```bash
python3 sync.py --real-run
```
Кодът вече НЕ се пипа за смяна на режима.

## Стъпка 6 — нощна автоматизация (cron, Linux)
```bash
crontab -e
# всяка нощ в 03:00
0 3 * * * cd /път/до/easyrea-sync && DRY_RUN=0 /usr/bin/python3 sync.py >> sync.log 2>&1
```

## Metafield за датата (за да се вижда на клиента)
Скриптът записва датата в `custom.expected_arrival` (тип date).
За да я покажеш в темата (напр. "Очаквана наличност: 16.06.2026"):
Shopify админ → Settings → Custom data → Products → дефинирай metafield
`custom.expected_arrival`, после в темата покажи
`{{ product.metafields.custom.expected_arrival }}`.

## Важни бележки
- **Сигурност**: в кода вече няма тайни. Ако си качвал стара версия на
  скриптовете някъде (архив, имейл, git), ротирай easyrea паролата,
  Shopify Client Secret и Anthropic API ключа — те бяха записани в
  `import_products.py`.
- **Incapsula**: ако по някое време заявките започнат да връщат HTML вместо JSON
  (anti-bot блокаж), намали честотата или ми пиши — има резервен вариант с браузър.
- **Безкрайна наличност** (qteDispo=2147483647) при "на път" продукти се третира
  нормално като "на път" — наличност 0 + дата.
- **Варианти**: ако някой Shopify SKU е с буква (напр. 119510A), а easyrea го няма
  точно така, провери в отчета колоната `reason`. При нужда добавяме fallback по
  базов код.
